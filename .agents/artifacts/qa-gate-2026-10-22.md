## Findings raised and fixed during the gate

| # | Severity | Finding | Root cause | Fix |
| :-- | :-- | :--- | :--- | :-- |
| F1 | **P0** | With JavaScript disabled, **all 43 `.reveal` elements stayed at `opacity: 0`** — the page below the hero rendered blank. The scroll-reveal ships hidden and relies on an `IntersectionObserver` to show it. | No `<noscript>` fallback existed. | `Base.astro` now emits a `<noscript>` block that forces `.reveal { opacity: 1; transform: none }` and hides the copy button (which cannot work without script). |
| F2 | **P1** | The mobile menu sheet overflowed the viewport at 375px and 768px — `nav.nav-sheet` and its links measured `x = -73` (off the left edge). | `.nav-actions` is a flex row without `justify-content`, so the group packed to the **start** of the row; the absolutely-positioned sheet then anchored to the menu button instead of the viewport edge. | `.nav-actions { justify-content: flex-end }` and `.nav-sheet { max-inline-size: calc(100vw - var(--gutter) * 2) }`. |
| F3 | **P1** | The copy button's failure hint read "Press ⌘C" on every platform. | The hint was hardcoded to the Mac modifier. | The hint now names the platform's modifier (`⌘C` on Apple, `Ctrl+C` elsewhere). |
| F4 | P1 | The docs page `<h1>` was the single word "Docs" — thin for SEO and for a scannable page. | — | Now "Muse Memory documentation". |
| F5 | P1 | axe-core: `definition-list` violation — a `<p>` sat inside a `<dl>`'s wrapper `<div>`. | `<p>` is not a permitted child of a `dl > div`. | The note became a second `<dd>`. |
| F6 | P2 | Two animated elements used `filter: blur()` together with a transform animation — a full re-rasterisation of the blur on every frame (a jank trap on low-end devices). | The blur was used to soften the gradients. | The softness now comes from the gradient stops themselves; the `filter` is gone and the elements animate on the compositor. |
| F7 | — | The gate's own copy check raced the async clipboard write. | The attribute was read synchronously after the click. | The check now waits for the feedback attribute (verified stable across three consecutive runs). |
| F8 | **P1** | The header rendered as raw inline text — "ProblemDemoArchitectureSurfaceCompareDocs" ran together, with no bar, no background and no sticky behaviour. | The `global.css` rewrite dropped the `.nav` / `.nav-inner` / `.nav-links` rules, and the `Nav.astro` scoped block never replaced them. **A missing CSS rule does not throw** — the element just takes its browser defaults, which is invisible to an overflow check and to axe. | The header chrome moved into `Nav.astro`'s scoped block, where it cannot drift away from the markup, and a new gate check (6b) now measures it. |
| F9 | — | The gate's own server did not strip the `/musememory` base path, so every stylesheet 404'd and the page rendered unstyled — a false positive that looked exactly like F8. | The server joined the request path onto the dist root without removing the base. | The server now strips the base path, and check 6b would have caught the difference. |

## Scope notes (not blocking)

- **WebKit** was not exercised — the engine is not installed in this environment. It is
  reported as skipped. Install with `bunx playwright-core install webkit` and re-run the
  gate before a release that claims WebKit coverage.
- **No load gate** was run: this is a static marketing site with no request path to
  saturate. The gate checklist's load clause does not apply.
- **No analytics** exist by design — the product ships no telemetry. Nothing to fire.
- **Data isolation, RLS, store-candidate and dependency-advisory clauses** in the
  qa-launch gate apply to a data product with a database. This release changes a static
  site and the npm package's published file list; no schema, RLS policy or store
  candidate is involved.

## Rollback

| Path | How |
| :--- | :--- |
| Site | Redeploy the previous tag (`git revert` the release merge, or re-run the Pages workflow on the previous SHA). The Pages workflow rebuilds from source, so a revert is a clean rollback. |
| Showreel | The committed `public/showreel.mp4` and `showreel-poster.png` are the only binary artefacts. Reverting the commit restores the previous pair. |
| npm | `npm dist-tag add musememory@3.0.1 latest` restores the previous `latest`; a new version cannot be unpublished, only de-tagged. |
| Package files | The npm `files` list gained `claims.json` and three docs. Removing them is a one-line change with no code impact. |

**Rollback owner**: the repository owner. This is a single-operator repository; the
owner can execute the rollback alone, which the gate checklist requires before a Ship
verdict.

## Re-run

```bash
bun run site:build     # rebuild the candidate
bun run site:qa        # re-execute every check above
```

The gate is deterministic: it exits non-zero on any blocking failure, so it can be
wired straight into CI.
