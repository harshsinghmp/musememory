# 📸 Reference Screenshots & UI Mockups

Drop reference screenshots, Figma exports, wireframes, and design snapshots into this folder.

## How AI Agents Use This Directory
1. **Visual Fidelity**: Vision-capable coding agents inspect files in this directory before styling pages, hero sections, pricing tables, or complex dashboards.
2. **Naming Convention**:
   - `[page-or-component-name]-[breakpoint-or-variant].png` (e.g., `hero-desktop.png`, `checkout-mobile.png`, `pricing-card-dark.png`).
3. **Format**: PNG, JPG, or WebP.
