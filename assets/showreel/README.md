# Terminal Showreel (T-423)

A reproducible terminal demo for v3.0.0. The recording itself is produced by a
human on a machine with a terminal recorder; this directory ships the exact
script and the encoding recipe so the result is reviewable rather than ad hoc.

## Narrative

1. Capture a failure-attribution memory (`memory capture` with `type=failure`).
2. Recall it from a new shell and show the negative-memory warning.
3. Record a green test run and show the fix-pair negative candidate (T-144).
4. Show `memory brief` and the HOT.md compounding line (T-314).
5. Close on the store health gate (`memory health`).

## Record

```bash
# Prerequisites: asciinema, agg (or ffmpeg), and a built musememory CLI.
asciinema rec assets/showreel/terminal-demo.cast \
  --overwrite \
  --command "bash assets/showreel/demo-script.sh"

agg assets/showreel/terminal-demo.cast assets/muse-memory-demo.gif
ffmpeg -y -i assets/muse-memory-demo.gif \
  -movflags +faststart -pix_fmt yuv420p assets/showreel/terminal-demo.mp4
```

Keep the recording under 45 seconds and at 100x30 columns. The GIF in
`assets/muse-memory-demo.gif` is the publishable artifact; the `.cast` file is
the reviewable source of truth.

## Honest status

The script and recipe are committed. The binary recording must be produced on a
machine with a terminal; it is not generated by CI because asciinema is not a
build dependency.
