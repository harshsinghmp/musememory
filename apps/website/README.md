# @musememory/website

Marketing site for Muse Memory, built with Astro 5 (static output).

```bash
bun install            # from repo root (workspaces)
bun run site:dev       # dev server
bun run site:build     # static build → apps/website/dist
bun run site:preview   # preview the production build
```

Deployed to GitHub Pages via `.github/workflows/pages.yml` under the `/musememory` base path.
